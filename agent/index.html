NIE-SLA Agent

Rust 编写的 Linux VPS 采集器与固定诊断执行器 — 只主动 HTTPS 上报，不开放管理端口

安装方式

在管理后台“探针”页新增 TCP/VPS 节点后，点击“部署 Agent”，复制该节点专属命令到 VPS 执行。命令包含节点独立 Token、Agent ID、下载地址、期望版本与 manifest 哈希，不要混用或公开。

# 通用命令只用于理解流程，实际安装必须使用后台生成的完整命令 curl -fsSL https://你的Worker域名/install.sh | sudo sh

安装链依次校验 install.sh、setup.sh、cftz、SHA256SUMS、目标架构二进制与版本，用于发现传输损坏与产物错配。

职责

  • 低权限 nstatus-metrics 服务负责指标、TCP Ping、GeoIP 与校验后更新。
  • 常驻 root Manager nstatus-metrics-tasks 只接受 nodequality 与 ip_unlock 两个固定动作。
  • 固定动作入口脚本由当前站点分发已审计快照并校验 SHA-256，不接收任意命令、URL、参数、stdin、环境变量或计划。
  • NodeQuality 四项测试默认 f/y/y/y；IPv4 解锁运行 -4 -n -p 完整报告模式，保存有界完整报告与最终媒体解锁结果。
  • Agent 自动更新只接受更高语义版本，并校验 manifest 与二进制 SHA-256。
