NStatus Agent

轻量 VPS 系统指标采集 — CPU / 内存 / 磁盘 / 负载

一键安装

VPS 上执行以下命令，自动识别架构、下载二进制、安装 systemd 服务：

curl -fsSL install.sh | sudo sh

支持 amd64 / arm64 / arm，交互式填写 API 地址和 Token。

一键卸载

curl -fsSL setup.sh | sudo bash -s -- uninstall
