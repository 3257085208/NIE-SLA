# 从 NeZha / Komari / NodeGet 迁移

后台的「从其它面板导入」可以读取 NeZha、Komari、NodeGet 中的服务器列表，一次创建为 NIE-SLA 探针，并为每台 VPS 生成一条安装命令。迁移只处理节点清单与探针替换，不迁移历史监控数据。

## 准备工作

- 一个可以正常打开「探针」页面的 NIE-SLA 后台。
- 来源面板的访问地址（必须是公网 HTTPS 地址）与只读凭据：
  - NeZha：后台个人设置中创建的 `nzp_` 开头的 API Token，至少包含服务器读取权限。
  - Komari：后台创建的 API Key（需要能读取客户端列表）。
  - NodeGet：面板的 API Key。
- 目标 VPS 的 SSH 访问权限，用来执行生成的安装命令。

各来源的凭据要求：

| 来源 | 凭据 | 说明 |
| --- | --- | --- |
| NeZha | API Token（`nzp_` 开头） | 在 NeZha 后台个人设置中创建，至少包含服务器读取权限。 |
| Komari | API Key | 在 Komari 后台创建，需要能读取客户端列表。 |
| NodeGet | API Key | 使用 NodeGet 面板提供的 API Key。 |

凭据只用于本次预览与导入，不会保存到数据库，也不会出现在日志或接口返回内容里。

## 操作步骤

1. 打开后台「探针」页面，点击工具栏里的「从其它面板导入」。
2. 选择来源面板，填写面板地址与凭据，点击「预览」。
3. 预览表列出面板中的服务器：名称、分组、IP 与状态。
   - 「可导入」：NIE-SLA 中不存在同名或同 ID 的目标。
   - 「已存在」：之前导入过，默认不勾选。
4. 勾选需要迁移的节点，点击「导入选中」。
5. 导入完成后，每个节点下方会出现一条独立的安装命令；把它复制到对应的 VPS 上执行。

导入的目标默认使用无公网 IP（NAT）模式与 300 秒探测间隔，可以在探针列表中按实际情况修改。

## 安装命令会自动替换旧探针

迁移生成的命令在安装 NIE-SLA Agent 时附带 `--replace-agent <来源>`：

- 安装器检测到对应来源的旧探针服务（systemd 或 OpenRC）时，先停止服务并禁用开机自启，再安装 NIE-SLA Agent，避免两套探针同时上报。
- 只停止和禁用服务，**不删除任何文件**；需要回滚时重新启用旧服务即可。
- 没有发现旧服务时输出「未发现 <来源> 旧探针服务（跳过）」，不影响本次安装。
- 如果旧探针还要保留（例如暂时并行对比），执行前手动去掉命令末尾的 `--replace-agent` 参数即可。

安装器也支持手动指定：

```bash
sudo bash install.sh --replace-agent auto          # 自动检测三种来源
sudo bash install.sh --replace-agent nezha         # 只处理 NeZha
```

`--replace-agent komari`、`--replace-agent nodeget` 同理；环境变量 `NIE_SLA_REPLACE_AGENT` 与参数等价。完整行为见 [Agent 文档](zh-CN/04-agent.md)。

## 命令与凭据说明

- 每条命令只对一台 VPS 有效，包含 10 分钟有效的一次性安装凭据；过期后在该节点的探针详情中重新生成即可。
- 命令中的注释行 `# NIE-SLA target: <目标 ID>` 用于核对命令归属，可以随命令一起执行。
- 不要复用其它节点的命令；节点身份与凭据是绑定的。

## NodeGet 的节点名称

NodeGet 只按 UUID 标识节点，接口不返回名称，导入后的目标名就是 UUID。导入结果会提示「名称需导入后补」，在探针列表中重命名即可，不影响上报与图表。

## 迁移后检查

- 约 5 分钟内，节点应在探针列表中显示在线并开始上报指标。
- 旧探针服务应处于停止且禁用状态；用 `systemctl status <旧服务名>` 或 `rc-service <旧服务名> status` 确认。
- 如需确认替换行为，可在安装日志中查找 `已停止`、`已禁用` 与末尾的汇总行。

## 失败排查

| 现象 | 原因与处理 |
| --- | --- |
| 提示「面板地址必须为 HTTPS」 | 地址填成了 `http://`，或地址中带有账号密码；改为面板的 HTTPS 地址后重试。 |
| 提示「面板凭据被拒绝」 | Token / API Key 无效或权限不足；在来源面板重新创建后重试。 |
| 提示「接口不存在（请确认版本/路径）」 | 来源面板版本过旧或接口路径不同；升级面板，或按其官方文档确认 API 路径。 |
| 提示「连接面板超时」 | NIE-SLA 到面板的网络不通；确认面板公网可达，且没有拦截 Cloudflare 出口。 |
| 预览结果为空 | 面板中没有节点，或凭据只能看到部分分组。 |
| 导入后节点一直离线 | 在该 VPS 上执行的必须是它自己那条命令；检查命令是否已超过 10 分钟或执行时报错。 |
| 旧探针仍在运行 | 安装命令被去掉了 `--replace-agent`，或旧服务名不在支持列表；可在该 VPS 手动停止并禁用旧服务。 |

## 说明

- 迁移不导入历史监控数据、流量统计或告警配置，只创建探针与安装命令。
- 同一面板可以重复预览；已存在的目标会标记为「已存在」，不会重复创建。
- 面板地址必须是公网 HTTPS 地址，导入过程不跟随跨主机重定向，避免凭据泄漏。
