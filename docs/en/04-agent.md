# Rust Agent

Run the per-node command generated by the admin panel. Installers verify the release version, checksum manifest, and binary checksum.

Linux installs:

- `nstatus-metrics`: unprivileged telemetry, Ping, GeoIP, and updates;
- `nstatus-metrics-tasks`: root runner for two fixed Beta actions.

Older installations must run the latest deployment command once to install the runner. Telemetry does not depend on it.

New installations enable verified Agent updates by default. systemd uses a timer and OpenRC uses an hourly job. The updater installs only a higher semantic version after validating the pinned manifest and binary SHA-256, and never performs an automatic downgrade. Older installations must run the latest deployment command once to install the root updater and the matching scheduler.

The Agent needs outbound HTTPS only. It does not listen on a remote-management port. GeoIP refreshes every 24 hours after success and retries after one hour on failure.
