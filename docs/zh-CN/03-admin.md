# 后台管理

## 登录与入口

后台使用账号密码与短期 Session。可选 GitHub OAuth 和 TOTP。后台路径可在设置中修改；修改后旧路径返回 404。路径不是秘密，也不能替代账号密码和限流。

## 探针

TCP/VPS 节点支持：

- 名称、分组、排序、商家、自定义商家；
- 现有机器类型；
- 价格、币种、计费周期、到期时间；
- 独立流量重置日、额度和统计方式；
- 标签、报警阈值；
- 是否公开地址。

名称是主要必填项。未设置国家、城市或到期时间时仍可保存。

### 自动位置

国家与城市为只读，由 Agent 查询出口 IPv4/IPv6 后上报。服务商在“设置 → 自动地理位置”统一选择：IP.SB、Cloudflare、IPIP.net 或自定义 HTTPS JSON。

Cloudflare 模式只保证国家代码。定位失败不会阻止指标上报，Agent 会稍后重试。

### 商家与机器类型

商家目录保留；选择“自定义”后可以填写目录外名称。机器类型保留当前选项，不根据国家或服务商自动推断。

## Beta Agent 动作

每台启用的 Linux VPS 显示两个 Beta 按钮：

- “运行 NQ”：固定运行 NodeQuality，保存结构化报告并展示原报告链接；
- “检测 IP 解锁”：固定运行 IPv4 JSON 检测，结果显示在公开页。

同一 Agent 同时只能有一个排队或运行任务。任务可查看排队、运行、成功、失败、过期状态。排队任务可取消，运行中任务不能从后台强杀。

后台按 Agent 上报的能力分别启用任务按钮，并显示 `Manager 已接管`、`兼容模式`、`等待自动更新` 等状态。已有 root 更新通道的旧 Agent 会自动迁移；只有后台明确标出的极早期低权限安装需要执行一次修复，此后无需因新增固定动作再次部署。

### NQ 报告图床

NQ 的“网络质量”和“回程路由”会由 Worker 渲染为自包含 SVG，再通过固定的 S3 渠道上传。上传目录固定为空，后台不提供图床设置或测试入口，也不存在可供浏览器读取、修改或代为上传的图床 API。

- 上传地址、API Token 与可选渠道名只存在于 Worker Secret，不写入开源代码、前端或 Agent；
- 只有管理员创建并由对应 Agent 认证完成的 NQ 任务会触发上传，不能把 Worker 当作通用图床代理；
- 公开报告只返回 NIE-SLA 同源图片代理地址，上游图床域名、响应地址和 Token 都不会进入浏览器；
- 上传仅接受公网 HTTPS 地址，不跟随上传重定向，图片响应地址也会再次校验；
- 普通备份不包含旧版图床配置；兼容迁移数据只进入密码保护的敏感备份；
- 图床失败不会把 NQ 任务判为失败，前端会回退到原始文本报告；
- 只处理配置生效后的新报告，旧报告不会自动补传。

## Ping 与 Latency

- Agent TCP Ping：从每台 VPS 测量后台配置的 TCP 目标。
- External Latency Agent：从独立网络位置测量公开 TCP 目标。
- Cloudflare Latency：Cloudflare 主动连接公开目标。

三者互相独立。Agent 在线不代表 Cloudflare 可以访问目标端口。

## 通知

Telegram 与邮件都支持测试、启停、格式与模板。先完成测试通知，再开启离线、恢复、资源、流量和到期规则。

## 外观

内置前端支持站点名、浏览器标题、Favicon、左上角 Logo、页头副标题、右上角图片或文字、页脚、颜色、文案与模块显隐。保存后公开页下次刷新状态时生效。

## 第三方主题

“主题”页面可上传符合 `nie-sla-theme-v1` 的 ZIP。上传或覆盖更新后默认停用，一次最多启用一个主题；停用即恢复原版。

- CSS 主题只覆盖公开状态页样式，不执行 JavaScript；
- Canvas 主题在无同源权限的 iframe 中运行，只能读取脱敏公开状态；
- 浏览器与 Worker 双重核对 ZIP SHA-256；
- 插件、市场导入和任意扩展执行不开放。

完整 Manifest、消息协议和发布规范见[第三方主题开发规范](14-third-party-themes.md)。

## 备份恢复

设置页可导出普通备份或密码保护的受保护备份。受保护凭据默认勾选；其中的每节点 Agent Token 会在恢复时使用当前部署的加密材料重新封装，使原节点在新 D1 上继续认证。恢复前必须先预览，并输入明确确认。支持合并与替换两种模式；Worker 会在 R2 自动保存恢复前快照。

备份密码至少 10 位。普通备份不含 Agent Token；高频历史不包含在 JSON 中，迁移时优先复用原 R2。

Agent 设置中的“Agent 连接域名”只接受公网 HTTPS Origin。该域名需要预先路由到当前 Worker，并能提供 `/api`、安装脚本和 `/bin`；保存后 Agent、Latency 安装命令与自动更新会统一使用它。
