# 后台管理

后台使用账号密码与短期 Session，可选 GitHub OAuth 与 TOTP。后台路径可在设置中修改，修改后旧入口返回 404；路径不是身份认证，真正的边界仍是账号密码与 Session。

## 探针

TCP/VPS 节点支持名称、分组、排序、商家、机器类型、价格、币种、计费周期、到期时间、独立流量重置日、额度、统计方式、标签、报警阈值与公开地址开关。名称是主要必填项；国家、城市与到期时间未设置时仍可保存。

国家与城市是只读字段，由 Agent 查询出口 IPv4/IPv6 后上报。服务商在“设置 → 自动地理位置”统一选择：IP.SB、Cloudflare、IPIP.net 或自定义 HTTPS JSON。Cloudflare 模式只保证国家代码。定位失败不会阻止指标上报，Agent 会稍后重试。

商家目录保留，选择“自定义”后可以填写目录外名称；机器类型保留当前选项，不自动推断。

## Beta Agent 动作

每台启用的 Linux VPS 有两个按钮：

- “运行 NQ”：固定运行 NodeQuality，保存结构化报告并展示原报告链接。
- “检测 IP 解锁”：固定运行 IPv4 完整报告模式（`-4 -n -p`），保存有界完整报告与最终媒体解锁结果，公开页只显示媒体解锁结果。

同一 Agent 同时只能有一个排队或运行任务。任务状态包括排队、运行、成功、失败与过期；排队任务可以取消，运行中任务可以标记强制停止，Agent 检测到取消标志后终止整个脚本进程组。

按钮按 Agent 上报的能力显示，并标注 `Manager 已接管`、`兼容模式`、`等待自动更新` 等状态。已有 root 更新通道的旧 Agent 会自动迁移；只有后台明确标出的极早期低权限安装需要执行一次修复。

NQ 的“网络质量”与“回程路由”由 Worker 渲染为自包含 SVG，通过固定渠道上传：

- 上传地址、API Token 与渠道名只存在于 Worker Secret。
- 只有管理员创建并由对应 Agent 认证完成的任务会触发上传。
- 公开报告只返回同源代理地址，上游图床地址不进入浏览器。
- 上传失败不判任务失败，前端回退到原始文本报告。

## Ping 与 Latency

Agent TCP Ping、External Latency Agent 与 Cloudflare Latency 三者独立。Agent 在线不代表 Cloudflare 可以访问目标端口，反之亦然。

## 通知

Telegram 与邮件都支持测试、启停、格式与模板。先完成测试通知，再开启离线、恢复、资源、流量与到期规则。

## 外观

内置前端支持站点名、浏览器标题、Favicon、Logo、页头副标题、右上角图片或文字、页脚、颜色、文案与模块显隐。保存后公开页下次刷新状态时生效。

## 第三方主题

“主题”页面上传符合 `nie-sla-theme-v1` 的 ZIP，上传或覆盖后默认停用，一次最多启用一个主题，停用即恢复原版。CSS 主题只覆盖样式；Canvas 主题在无同源权限的 iframe 中运行，只能读取脱敏公开状态。插件、市场导入与任意扩展执行不开放。完整规范见[第三方主题开发规范](14-third-party-themes.md)。

## 备份恢复

设置页可导出普通备份或密码保护的受保护备份。受保护备份中的每节点 Agent Token 在恢复时用当前部署的加密材料重新封装，原节点在新 D1 上可以继续认证。恢复前必须先预览并输入确认词；支持合并与替换两种模式，Worker 会在 R2 自动保存恢复前快照。

备份密码至少 10 位。普通备份不含 Agent Token；高频历史不在 JSON 中，迁移时优先复用原 R2。

“设置 → Agent → Agent 连接域名”只接受公网 HTTPS Origin，需要预先路由到当前 Worker 并能提供 `/api`、安装脚本与 `/bin`。保存后 Agent、Latency 安装命令与自动更新统一使用该地址。
