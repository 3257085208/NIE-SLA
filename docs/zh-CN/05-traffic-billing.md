# 05 流量与账单

流量和账单配置属于单台 VPS，不是全局统一值。

## 数据来源

Agent 上报网卡累计接收/发送字节和瞬时速率。Worker 根据连续两次累计值计算增量；页面与报警会把 D1 周期行和尚未落盘的最新计数差值合并，因此仍按每次 5 分钟上报实时显示。周期行最多每 30 分钟持久化一次，跨天、计数器回绕或周期变化会立即处理；跨天后的第一次落盘会把前一天封存到 D1 每日账本。VPS 重启、计数器回绕或网卡变化时，不会把负差值当作流量扣除。

```text
本次增量 = max(0, 当前累计 - 上次累计)
```

## 开启步骤

1. 后台编辑目标。
2. 开启流量累计。
3. 填写额度 GB；`0` 表示不设置上限。
4. 设置每月流量重置日（1–31）。
5. 选择统计模式。
6. 保存并等待下一批 Agent 指标。

## 统计模式

| 模式 | 计算 |
| --- | --- |
| 双向合计 | `rx + tx` |
| 仅下行 | `rx` |
| 仅上行 | `tx` |
| 较大方向 | `max(rx, tx)` |

应根据服务商计费规则选择，而不是根据页面哪个数字更好看。

## 周期重置

流量重置日是独立字段，不再从 VPS 到期时间推导。设置为 1 时按自然月统计；设置为 24 时，周期为本月 24 日至下月 24 日。

对于 29、30、31 日，较短月份使用当月最后一天。到期时间只用于到期展示和报警，续期或修改到期时间不会改变流量周期。

修改流量重置日会立即切换当前周期。Worker 会重新汇总新周期范围内已经封存的每日流量，并加上当天尚未封存的流量；不会清空网卡计数基线，也不会从零重新累计。页面数值可能变大或变小，这是因为新周期包含的日期发生了变化。

## 账单字段

- `price`：标价。
- `currency`：USD/CNY 等。
- `billing_cycle`：月付、年付、一次性、按小时等。
- `expires_at`：到期时间。
- `traffic_reset_day`：独立的每月流量重置日，范围 1–31。
- `location`、`tags`：展示与筛选信息。

汇率显示只是估算，不应作为财务结算依据。

## 精度和限制

- 流量累计精度取决于 Agent 上报间隔，不是每个数据包实时写 D1。
- 同一天的高频上报只更新当前周期行，不会每次新增每日行；每台 Agent 通常每天只增加一条每日记录。
- 修改重置日只读取相关周期内约一个月的每日记录，正常浏览不会反复扫描每日账本。
- Agent 离线期间无法记录该机流量；恢复后能否补齐取决于系统累计计数是否连续。
- 重装系统、网卡重置会中断累计基线。
- 容器/veth 等虚拟网卡可能造成重复计数，应确认 Agent 选择的接口符合预期。
- 页面周期汇总由 D1 已落盘值与最新网卡计数差值组成，每日账本用于重算；前端瞬时速率不是周期流量。

## 报警

支持剩余百分比和剩余 GB。只有配置了 quota 时百分比才有意义。单台 VPS 可以覆盖全局流量报警阈值。

## 排障

流量为 0 时检查：Agent 在线、目标已启用流量、最新指标包含累计网络字段、周期正确、模式正确。不要通过删除 D1 记录重置，除非明确知道当前周期键和后果。
