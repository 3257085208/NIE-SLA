# 05 流量与账单

## 单台 VPS 独立配置

流量统计不是全局设置。每台 VPS 都可以单独启用、设置月流量上限 GB、选择计费方式，并根据到期时间决定重置日。

## 计费方式

| 模式 | 说明 |
| --- | --- |
| 双向合计 | 上行 + 下行 |
| 仅上行 | 只算出站 |
| 仅下行 | 只算入站 |
| 上下行较大值 | max(上行, 下行) |

如果商家写“双向流量”，通常选双向合计；如果商家只算出网，选仅上行。

## 重置日期

- 未设置到期时间：自然月 1 日重置。
- 设置到期时间：按到期时间日号重置。例如到期时间 `2027-01-12`，则每月 12 日重置。

## 特殊套餐

小时计费云主机通常没有固定到期时间，可以留空并选择“小时计费”。买断制/永久 VPS 可以留空并选择“买断/永久”。

## 精度说明

流量根据系统网卡累计值做差值累计，适合月度提醒，但不是运营商账单级精度。重启、网卡变更、容器网络可能造成轻微偏差。
