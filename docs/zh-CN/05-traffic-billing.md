# 05 流量与账单

流量和账单配置属于单台 VPS，不是全局统一值。

## 数据来源

Agent 上报网卡累计接收/发送字节和瞬时速率。Worker 根据连续两次累计值计算增量，并写入 D1 的月周期记录。VPS 重启、计数器回绕或网卡变化时，不会把负差值当作流量扣除。

```text
本次增量 = max(0, 当前累计 - 上次累计)
```

## 开启步骤

1. 后台编辑目标。
2. 开启流量累计。
3. 填写额度 GB；`0` 表示不设置上限。
4. 选择统计模式。
5. 保存并等待下一批 Agent 指标。

## 统计模式

| 模式 | 计算 |
| --- | --- |
| 双向合计 | `rx + tx` |
| 仅下行 | `rx` |
| 仅上行 | `tx` |
| 较大方向 | `max(rx, tx)` |

应根据服务商计费规则选择，而不是根据页面哪个数字更好看。

## 周期重置

未设置到期时间时按自然月：当月 1 日至下月 1 日。

设置到期时间时，使用到期日号作为每月重置日。例如到期时间是 2027-01-12，则周期通常为本月 12 日到下月 12 日。对于 29/30/31 日，短月份会按实现归一到有效日期。

修改到期日可能改变当前周期边界。修改前记录当前累计，避免误解为数据丢失。

## 账单字段

- `price`：标价。
- `currency`：USD/CNY 等。
- `billing_cycle`：月付、年付、一次性、按小时等。
- `expires_at`：到期时间。
- `location`、`tags`：展示与筛选信息。

汇率显示只是估算，不应作为财务结算依据。

## 精度和限制

- 流量累计精度取决于 Agent 上报间隔，不是每个数据包实时写 D1。
- Agent 离线期间无法记录该机流量；恢复后能否补齐取决于系统累计计数是否连续。
- 重装系统、网卡重置会中断累计基线。
- 容器/veth 等虚拟网卡可能造成重复计数，应确认 Agent 选择的接口符合预期。
- D1 中的月累计是权威显示值，前端瞬时速率不是月流量。

## 报警

支持剩余百分比和剩余 GB。只有配置了 quota 时百分比才有意义。单台 VPS 可以覆盖全局流量报警阈值。

## 排障

流量为 0 时检查：Agent 在线、目标已启用流量、最新指标包含累计网络字段、周期正确、模式正确。不要通过删除 D1 记录重置，除非明确知道当前周期键和后果。
