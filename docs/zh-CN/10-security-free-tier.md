# 安全与免费额度

## 安全边界

- 管理员账号密码建立短期 Session。
- GitHub OAuth 默认关闭，并要求用户名白名单。
- TOTP 默认关闭，开启后密码与 OAuth 都不能绕过。
- 每台 Agent 使用独立 scoped Token。
- Agent Token 以哈希认证，可恢复副本加密保存。
- 公共接口裁剪秘密字段，并可掩码 IP/端口。
- 安装与更新执行版本、manifest 和二进制校验。
- 不提供 Web Shell、任意命令、任意参数或任意定时脚本。
- 第三方 CSS 主题不执行脚本；Canvas 主题在无同源权限的沙箱中运行，只能使用 `status:read` 白名单桥接。
- 主题 ZIP 有大小、文件数、路径、类型、Manifest 与 SHA-256 校验，上传后默认停用。
- 插件、后台脚本、市场导入和任意扩展执行不开放。
- 敏感备份使用 PBKDF2-SHA256 与 AES-256-GCM。

Beta 动作需要 root 权限，因此与主遥测服务分离。Manager 只接受 Worker 返回且本地二进制同样支持的动作枚举；管理员不能提交 Shell 文本、URL、参数、stdin、环境或计划。脚本子进程会清空 Agent 环境，并限制下载大小、超时和输出；每节点 Token 即使泄露也不具备后台管理权限。

NodeQuality 与 IP.Check.Place 动作仍会下载并执行对应服务当前提供的脚本及其依赖，这属于两个 Beta 功能明确保留的外部信任边界。只应在认可相应提供方时手动触发，关闭或不触发不会影响监控。Agent 更新的 manifest 哈希由同一 Worker 策略提供，可防止传输损坏和错误文件，但不能替代独立离线发布签名；Worker 或发布环境失陷仍属于运维风险。

自定义 GeoIP URL 只允许公开 HTTPS，并拒绝显式本机、内网与云元数据地址。管理员仍应只使用可信服务。

## 备份

普通备份不含凭据。敏感备份密码至少 10 位，文件与密码应分开保存。恢复前自动写 R2 快照，但快照不能替代离线备份。

## 免费额度

实际额度取决于 VPS 数量、公开访问量、Ping 数量、重试、历史范围和报警。

默认设计：

- Cron 每分钟更新当前状态；
- Agent 仍按 5 分钟上传，当前 Metrics 在 D1 保留一行最新状态；
- D1 使用 5 分钟 SLA 桶，30 天汇总优先读取 R2 中的增量日统计，异常落后时才按目标回查 D1；
- 高频 Metrics/Ping 先进入每 Agent 隔离的 Durable Object，当前小时可直接读取，结束后每小时合并写一次 R2；
- 流量页面合并尚未落盘的网卡计数差值，D1 周期账本最多每 30 分钟持久化一次；
- 凭据活跃时间最多每 6 小时写一次，状态快照每 5 分钟写一次 R2；
- 公共接口限制历史范围和最大采样点。

按 100 台 VPS、全部开启流量统计、2 个 External Latency Agent、Agent 每 5 分钟上传、当前状态每分钟刷新估算：

| 资源 | 估算 | 当前免费上限 | 余量 |
| --- | ---: | ---: | ---: |
| Workers/DO 请求 | 约 86,448 次/天 | 100,000 次/天 | 约 13,552 次/天供页面与 API |
| D1 写入行 | 约 95,400 行/天 | 100,000 行/天 | 约 4,600 行/天 |
| D1 读取行 | 正常约 100-250 万行/天 | 5,000,000 行/天 | 视后台与公开访问量变化 |
| R2 Class A | 约 210,240 次/月 | 1,000,000 次/月 | 约 789,760 次/月 |

因此默认配置可把 **100 台 + 5 分钟上传** 控制在免费额度的理论范围内，而且没有降低 Agent 上传频率、当前状态刷新频率或前端功能。D1 写入是最紧的指标；大量后台操作、异常重试、通知状态变化、超过 2 个 Latency Agent 或修改默认间隔都会占用余量。公开页面访问还会占用 Workers 请求，流量较大时应开启 Cloudflare 缓存并持续观察 Dashboard，不能把理论值当作永久保证。

上线前应在 Cloudflare Dashboard 设置用量告警，并定期查看 D1、R2、Workers 和 Durable Objects 指标。
